# v0 Builder Week 2026

A modern web development project built with Next.js, showcasing best practices for building scalable applications on the v0 platform.

## Overview

This project demonstrates building production-ready applications using Next.js, React, TypeScript, and Tailwind CSS during v0's Builder Week 2026 initiative.

## Getting Started

### Prerequisites
- Node.js 18+ 
- npm or pnpm

### Installation

```bash
npm install
# or
pnpm install
```

### Development

```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

## Tech Stack

- **Framework**: Next.js 16
- **UI Library**: React 19
- **Styling**: Tailwind CSS
- **Components**: shadcn/ui
- **Language**: TypeScript
